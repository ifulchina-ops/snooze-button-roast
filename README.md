A one-line snooze button roast for make.fun's "Snooze Button Roast" bounty ($2, top 10, 1st $0.64). The alarm clock rings at 6 AM on a Saturday like it pays rent in the house, so the roast fires it from the only job it ever had: waking its owner up. On a Saturday, of all days — the one morning the whole week exists for — it gets the sack.

## Run it

```sh
node main.ts
```

It writes the roast to `/output/entry.txt` (one line, 123 characters).
